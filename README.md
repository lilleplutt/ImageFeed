## **ImageFeed**

ImageFeed — приложение для просмотра фотографий из сервиса Unsplash. Пользователь авторизуется через OAuth 2.0, листает ленту фотографий, ставит лайки и просматривает свой профиль.

## **Ссылки**

[API Unsplash](https://unsplash.com/developers)

## **Описание приложения**

- Многостраничное приложение с лентой фотографий, загружаемых через Unsplash API.
- Пользователь проходит авторизацию через OAuth 2.0 и получает доступ к персонализированному контенту.
- В ленте можно листать фотографии, ставить и убирать лайки, а также открывать снимок в полноэкранном режиме.
- На экране профиля отображается информация об авторизованном пользователе Unsplash: аватар, никнейм и описание.

## **Функциональные требования**

- При запуске приложения показывается сплеш-скрин; если пользователь не авторизован, открывается экран входа;
- Авторизация выполняется через OAuth 2.0 с использованием WebView; после успешного входа пользователь попадает в приложение;
- На главном экране отображается лента фотографий с пагинацией: новые фото подгружаются по мере прокрутки;
- Пользователь может поставить лайк или убрать его, нажав на кнопку сердца в ячейке ленты;
- По нажатию на фото открывается экран полноэкранного просмотра с поддержкой зума и прокрутки;
- На экране профиля отображаются аватар пользователя, имя, никнейм и описание, загруженные из Unsplash API;
- Пользователь может выйти из аккаунта; при этом токен удаляется и происходит возврат на экран авторизации.

## **Технические требования**

- Приложение поддерживает устройства iPhone с iOS 13;
- Язык реализации — Swift; UI-фреймворк — UIKit;
- Архитектура — MVP;
- Сетевые запросы реализованы через URLSession;
- Авторизация — OAuth 2.0 (Unsplash);
- Покрытие кода unit-тестами и UI-тестами (XCTest).
